# MotorTracker Yamaha (Armawjy)

Aplikasi pintar untuk melacak perjalanan, memantau kecepatan (Speedometer), dan manajemen perawatan motor Yamaha Anda secara otomatis menggunakan GPS.

## 📥 Link Download (APK)
Klik link di bawah ini untuk mendownload dan menginstall aplikasi langsung di HP Anda melalui Google Drive:
> **[Download app-debug.apk (Google Drive)](https://drive.google.com/drive/folders/1HRVIMbYi3CfvFA-Y4ye7QYgdQTP1gEGJ)**

*Catatan: Jika muncul peringatan keamanan, pilih "Tetap Install" (Install Anyway).*

## 🚀 Fitur Utama
- **Speedometer Analog & Digital**: Tampilan jarum merah ikonik yang bergerak real-time mengikuti kecepatan motor Anda.
- **Smart Odometer**: Gabungan antara Odometer Fisik (asli dari motor) dan Odometer Digital (hasil rekaman GPS).
- **Tracking Otomatis**: Aplikasi otomatis merekam perjalanan jika mendeteksi motor melaju di atas 5 KM/Jam.
- **Log Perawatan**: Pengingat ganti oli dan servis rutin agar motor tetap dalam kondisi prima.
- **Riwayat Rute**: Mencatat rute, alamat titik awal, titik akhir, dan waktu tempuh secara detail.

## 📲 Cara Menginstall di HP (Tanpa Play Store)
Anda bisa membagikan aplikasi ini kepada siapa saja hanya melalui sebuah **Link**. Berikut caranya:

### 1. Buat File APK (Di Android Studio)
- Di laptop Anda, buka Android Studio.
- Klik menu **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
- Tunggu sampai selesai, lalu klik **Locate** untuk melihat file `app-debug.apk` atau `app-release.apk`.

### 2. Bagikan Lewat Link
- Upload file APK tersebut ke **Google Drive**, **MediaFire**, atau langsung ke **GitHub Releases**.
- Salin link file yang sudah di-upload tadi.
- Kirim link tersebut ke HP orang lain melalui WhatsApp atau Media Sosial.

### 3. Cara Install di HP Penerima
- Klik link download dan simpan file APK-nya.
- Buka file APK tersebut.
- Jika muncul peringatan keamanan, pilih **Settings** (Pengaturan) lalu aktifkan/centang **"Allow from this source"** (Izinkan dari sumber ini).
- Klik **Install** dan selesai! Aplikasi siap digunakan.

## 🛠️ Cara Menggunakan Aplikasi
1. **Setting Awal**: Buka menu **Profil**, masukkan angka speedometer motor Anda saat ini di bagian "Odometer Fisik".
2. **Mulai Jalan**: Buka tab **Perjalanan**. Anda bisa tekan tombol "MULAI PERJALANAN" atau langsung tancap gas motor Anda.
3. **Pantau Kecepatan**: Jarum merah akan otomatis naik mengikuti tarikan gas motor Anda.
4. **Selesai**: Perjalanan akan tersimpan otomatis ke menu **Riwayat** saat Anda berhenti lama atau menekan tombol "SELESAI".

## 💻 Cara Menjalankan Project (Developer)

2. Buka di Android Studio terbaru.
3. Pastikan HP atau Emulator memiliki akses **Google Play Services** untuk fitur GPS.
4. Jalankan (Run) ke perangkat Anda.
